# Trade-offs

Every significant design decision in this project is recorded here, one file per decision, with the options considered and the reasoning. To add one, copy the template below.

## Template

Use this structure for each new file. Keep Context and Decision under 100 words, and each Description under 100 words. Keep each pro and con under 50 words, ideally under 20.

```
# Name of the trade-off

## Context

Why this decision came up.

## Options considered

### Option 1: name

#### Description

#### Pros

- ...

#### Cons

- ...

### Option 2: name

(same structure)

## Decision

What was chosen and why.
```
